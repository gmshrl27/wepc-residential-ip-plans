## 住宅 IP、家宽 IP、双 ISP 差在哪

先说清这几个词，因为它们决定了同一个地区为什么会有两三个价位。

**原生 IP** 指 IP 归属地和机房物理位置一致，注册地就是当地，这是基础门槛。**住宅 IP** 指 ISP 分配给家庭用户的地址池。**家宽 IP 或静态家宽 IPv4** 是固定不变的住宅 IP，租期内不会动态切换。**双 ISP 家宽** 则把 IP 注册 ISP 和实际承载 ISP 分开，伪装层级更高，是这几类里最接近真实住户的一档。

纯净度排序大致是：双 ISP 家宽 > 静态家宽 / 住宅 > 普通原生 > 机房 IP，价格也按这个顺序往上走。机房 IP 在平台眼里太容易识别，数据中心段位一眼就被归类成服务器环境，这就是做 TikTok 这类业务要换住宅出口的原因。

贵在资源，不在带宽。真实民宅线路每条宽带能分配的 IP 数量极少，扩容必须真实装机；机房 IP 可以批量生成。所以同带宽下，静态住宅 IP 的月价通常是机房 IP 的 2 到 5 倍，这个价差是结构性的，不会因为商家促销消失。

名字叫“住宅”不等于 ASN 就是 ISP。市面上不少产品其实是长效静态，IP 固定、线路仍在机房或城域网，检测时会判成 hosting；还有把“会话保持”叫静态的，底层依旧是动态池，租到第三周突然换了城市，账号立刻被风控标记。买之前查一下 ASN，比看商品标题有用。

顺带做个价格参照。国内平台的静态住宅 IP，2026 年 10 月核验的数据是月付最低 2.24 元起，主流档集中在 4 到 13 元/月。那些是中国地区的 IP，做国内电商和社媒完全够用；海外家宽要在当地真实装机，价格按澳元、日元、美元结算，两边不是同一套成本结构。拿 2 元档去说海外住宅 IP“贵”，比错了对象。

## 拿到 IP 后怎么验，四步就够

付完钱拿到 IP，别急着登号，先花十分钟走完这四步。

1. **查 ASN 归属。** 打开 `ipinfo.io/<你的IP>` 或 `bgp.he.net`，看 ASN 的运营方。AT&T、Comcast、Verizon、中国电信这类民用宽带运营商才算真住宅出身；Amazon、Google Cloud、阿里云、腾讯云、Vultr 是云厂商，各类带 Hosting、Data Center 字样的公司是机房。这一步能筛掉大部分伪住宅。
2. **过三个 IP 类型库。** `ipapi.is` 或 `ip-api.com` 看 type 字段，`IP2Location` 看 usage type，`Scamalytics` 看 fraud score。至少两个库标为 residential 或 ISP，且 fraud score 低于 25，才算通过。某个库标 hosting，说明这段 IP 被该库收录为机房，用在这家库的下游风控里照样会被识破。
3. **查黑名单与滥用记录。** AbuseIPDB 看近 90 天有没有举报，Spamhaus ZEN、SpamCop 这类 DNSBL 看是否被列入。IP 出身真是真，干净是干净，两件事。上一位用户拿它刷过单，你接手就是脏 IP。
4. **查 DNS、WebRTC 和时区。** 浏览器开 `browserleaks.com/webrtc` 和 `ipleak.net`，看有没有泄漏真实出口、DNS 解析走的是本地还是代理端、时区和语言是否与目标地区一致。三项都对上才算过关。

判定标准很干脆：**四步全过，可以用来养号；缺一条，只适合做采集。**

配置侧的坑也顺手提两句。只改 IP 不改时区和语言，风控看到的是一组自相矛盾的信号；DNS 没走代理，站点通过解析结果就能推断你不在当地；WebRTC 绕过代理直连 STUN 服务器，真实 IP 直接暴露；一条 IP 同时登多个账号，等于自己把号串起来。这些都不是 IP 质量问题，是设置问题。

**只做国内业务。** 国内静态住宅 IP 主流档 4 到 13 元/月，最低 2.24 元起，地区就是中国，做国内电商、社媒、本地生活完全够用。买海外 VPS 跑国内账号，钱花得没意义。

## 常见问题

**能不能只租一个月？**

能。月付原价下单，配 `WePCMON90` 打 9 折。不确定地区或档位是否合适，先月付跑一轮，别一上来签年付。

**住宅 IP 是不是就不会封号？**

不是。它解决的是“环境被判定为机房”这一类风险，能降低触发风控的概率，但内容质量、操作频率、账号行为仍然在平台规则里。四步验真全过只说明这条 IP 出身干净，不构成任何封号保险。

**年付中途不用了能退吗？**
